INTEGRATED TOOLS

Lebih Dari Sekadar Chat Biasa

Model AI secara cerdas memanggil fungsi tools bawaan ketika mendeteksi instruksi kalkulasi, pemrograman, pencarian, atau pemrosesan web.

Code Executor Sandbox

Python, JS, Go, Rust, C++, Java

Jalankan script pemrograman langsung di dalam chat. Hasil kompilasi dan log output terminal ditampilkan secara instan tanpa perlu beralih aplikasi.

print(sum([x**2 for x in range(1, 11)])) # -> 385

Kalkulator Matematika & Trigonometri

Aljabar, Matriks, Logaritma, Statistik

Menghindari halusinasi hitungan aritmatika pada LLM dengan mendelegasikan formula angka ke engine kalkulasi presisi tinggi.

sqrt(256) + log10(1000) * sin(pi/2) = 19

Pencarian Web Real-Time

Exa, Tavily, dan DuckDuckGo Engine

Memungkinkan model AI menyerap berita terbaru, dokumentasi library teranyar, atau fakta global sebelum menyusun jawaban komprehensif.

search("Gemini 2.5 Flash benchmarks 2026")

URL Reader & Unit Converter

Scrape Artikel Web & Konversi Satuan

Cukup tempelkan tautan URL website atau artikel panjang, AI akan membaca teks asli dan menyusun ringkasan poin-poin penting dalam hitungan detik.

Pertanyaan Yang Sering Diajukan

Tidak wajib. Anda hanya perlu mengisi kunci API dari provider yang Anda butuhkan. Pada provider OpenCode Zen, sudah tersedia 7 model gratis (seperti Big Pickle, DeepSeek V4 Flash Free, dan Nemotron 3 Ultra Free) yang bisa langsung dipakai tanpa saldo.
Saat prompt meminta eksekusi kode atau fakta terbaru, model AI akan secara otomatis memanggil runtime sandbox Python/JS atau mesin pencari web (Tavily/Exa/DDG) dan menyajikan hasilnya secara terpadu di chat.
Bisa. Pilih provider Custom / Self-Hosted lalu masukkan IP lokal laptop Anda (contoh: http://192.168.1.50:11434/v1). Ponsel dan laptop harus terhubung di jaringan Wi-Fi yang sama.
Sama sekali tidak. Kawan Model tidak memiliki backend penampung pesan. Semua riwayat chat disimpan di database SQLite lokal di ponsel Anda, dan kunci API disimpan di enkripsi SharedPreferences perangkat.
